### Метод конечных разностей для уравнения теплопроводности
 
**Задание:**  
Реализовать моделирование изменения температуры в пластине на основе одномерного уравнения теплопроводности с использованием метода конечных разностей.
 
Выполнить моделирование с различными шагами по времени и по пространству.  
Заполнить таблицу значений температуры в центральной точке пластины после 2 секунд модельного времени.

## 1. Постановка задачи и основное уравнение  
В данной работе реализовано моделирование одномерного процесса теплопроводности в пластине. В основе лежит дифференциальное уравнение теплопроводности:
 
$$\rho c \frac{\partial T}{\partial t} = \lambda \frac{\partial^2 T}{\partial x^2}$$
 
Где:  
- $\rho$ — плотность материала.  
- $c$ — удельная теплоемкость.  
- $\lambda$ — коэффициент теплопроводности.  
 
Начальные и граничные условия:  
- В начальный момент времени $t = 0$: $T = T_0$ для всей пластины.  
- На левой границе $x = 0$: $T = T_л$.  
- На правой границе $x = L$: $T = T_п$.  
 
## 2. Неявная конечно-разностная схема  
Для решения использована абсолютно устойчивая неявная схема. В отличие от явной схемы, она позволяет использовать любые шаги по времени и пространству без «развала» решения.  
 
Производные заменяются на разностные отношения:  
- По времени: $\frac{\partial T}{\partial t} \approx \frac{T_i^{n+1} - T_i^n}{\tau}$.  
- По пространству: $\frac{\partial^2 T}{\partial x^2} \approx \frac{T_{i+1}^{n+1} - 2T_i^{n+1} + T_{i-1}^{n+1}}{h^2}$.  
 
После подстановки уравнение приводится к виду системы линейных уравнений:  
$$A_i \cdot T_{i+1}^{n+1} - B_i \cdot T_i^{n+1} + C_i \cdot T_{i-1}^{n+1} = F_i$$  

Коэффициенты схемы:  
- $A_i = C_i = \frac{\lambda}{h^2}$  
- $B_i = \frac{2\lambda}{h^2} + \frac{\rho c}{\tau}$  
- $F_i = -\frac{\rho c}{\tau} T_i^n$  
 
       # Расчет коэффициентов:  
       A_val = lam / (dx**2)  
       C_val = lam / (dx**2)  
       B_val = (2 * lam / (dx**2)) + (rho * c / dt)  
       coeff_const = (rho * c / dt) # Часть для Fi
  
       # Внутри цикла по времени вычисляется правая часть Fi
       for _ in range(nt):
       rhs = coeff_const * T[1:-1]                    # Fi = -(rho*c/tau) * T_i^n
       rhs[0] += C_val * T[0]                         # Коррекция для левой границы
       rhs[-1] += A_val * T[-1]                       # Коррекция для правой границы

## 3. Алгоритм решения: Метод прогонки (Томаса)
Так как система уравнений имеет трехдиагональную матрицу, наиболее эффективным методом решения является метод прогонки. Он состоит из двух этапов:  
Прямой ход: вычисление прогоночных коэффициентов.  
Обратный ход: нахождение значений температуры от последней точки к первой.  

     # Реализация алгоритма в программе:
      def solve_tridiagonal(a, b, c, d):
        n = len(d)
        # Прямой ход
        for i in range(1, n):
            mc = ac[i-1] / bc[i-1]
            bc[i] -= mc * cc[i-1]
            dc[i] -= mc * dc[i-1]
        # Обратный ход
        res = np.zeros(n)
        res[-1] = dc[-1] / bc[-1]
        for i in range(n-2, -1, -1):
            res[i] = (dc[i] - cc[i] * res[i+1]) / bc[i]
        return res
