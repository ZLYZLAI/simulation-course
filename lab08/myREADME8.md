## 2. Теоретические сведения

### 2.1. Пуассоновский (простейший) поток

**Пуассоновский поток** - это поток случайных событий, обладающий тремя ключевыми свойствами:

- **Стационарность** - вероятность наступления $k$ событий на интервале длины $T$ зависит только от длины интервала, но не от его положения на оси времени.
- **Ординарность** - в один и тот же момент времени может наступить не более одного события.
- **Отсутствие последействия (независимость)** - число событий на любом интервале не зависит от числа событий на других, не пересекающихся с ним интервалах.

Поток характеризуется одним параметром - **интенсивностью** $\lambda$, которая задаёт среднее число событий в единицу времени.

### 2.2. Экспоненциальное распределение интервалов

Главное свойство простейшего потока: **интервалы $\tau$ между последовательными событиями** распределены по экспоненциальному закону с тем же параметром $\lambda$:

$$f(\tau) = \lambda \cdot e^{-\lambda \tau}, \quad \tau \geq 0$$

Математическое ожидание интервала:

$$M[\tau] = \frac{1}{\lambda}$$

Это означает: если интенсивность $\lambda = 5$ заявок/сек, то средний интервал между ними составляет $1/5 = 0{,}2$ сек.

**Генерация $\tau$ методом обратной функции.** Функция распределения экспоненциального закона:

$$F(\tau) = 1 - e^{-\lambda \tau}$$

Приравнивая $F(\tau) = \alpha$, где $\alpha \sim U(0, 1)$, и выражая $\tau$:

$$\tau = -\frac{\ln(1 - \alpha)}{\lambda} = -\frac{\ln \alpha}{\lambda}$$

Именно по этой формуле работает функция `numpy.random.exponential(scale=1/λ)`.

### 2.3. Распределение числа событий. Закон Пуассона

Число событий $X$, наступивших за интервал времени $T$, подчиняется **распределению Пуассона** с параметром $\mu = \lambda T$:

$$P(X = k) = \frac{(\lambda T)^k}{k!} \cdot e^{-\lambda T}, \quad k = 0, 1, 2, \ldots$$

Здесь:
- $k$ - конкретное число событий за интервал,
- $e \approx 2{,}718$ - основание натурального логарифма,
- $k!$ - факториал числа $k$,
- $\mu = \lambda T$ - параметр распределения.

**Теоретическое математическое ожидание:**

$$M[X] = \lambda T$$

**Теоретическая дисперсия:**

$$D[X] = \lambda T$$

Важнейшее свойство распределения Пуассона: **математическое ожидание равно дисперсии**. Это не совпадение, а аналитически доказанный факт, вытекающий из формулы выше. Ни у какого другого стандартного распределения такого свойства нет.

### 2.4. Параметр $\mu = \lambda T$

Параметр $\mu$ является единственным параметром распределения Пуассона. Его смысл прост: $\mu$ - это **ожидаемое число событий** за интервал длиной $T$. Если за секунду приходит $\lambda = 5$ заявок, то за $T = 2$ секунды ожидается $\mu = 10$ заявок. Именно значение $\mu$ полностью определяет форму распределения, и именно к нему сходятся и эмпирическое среднее, и эмпирическая дисперсия.

## 3. Алгоритм моделирования

### 3.1. Алгоритм 2: генерация на основе длинного потока

В данной работе применяется **Алгоритм 2**, который эффективнее Алгоритма 1, так как генерирует поток только один раз.

**Обоснование выбора.** Алгоритм 1 для каждого из $N$ экспериментов генерирует новый поток заново - это $N$ полных генераций. Алгоритм 2 использует свойство стационарности: раз вероятностная структура потока не зависит от начальной точки, можно сгенерировать один длинный поток и многократно «вырезать» из него случайные окна длины $T$.

**Описание алгоритма:**

1. Задать параметры: $\lambda$, $T$, $N$.
2. Выбрать длину длинного потока $T_1 \gg T$ (в реализации: $T_1 = \max(500 \cdot T,\ 5000/\lambda)$).
3. Сгенерировать один пуассоновский поток длиной $T_1$, получив массив моментов событий $\{t_1, t_2, \ldots, t_n\}$.
4. Повторить $N$ раз:
   - Сгенерировать случайное начало окна: $a \sim U(0,\ T_1 - T)$
   - Подсчитать число событий, попавших в полуинтервал $[a,\ a + T)$, - записать в $X_k$
5. Вычислить эмпирическое распределение: $P^*(X = k) = \dfrac{\#\{X_j = k\}}{N}$

### 3.2. Генерация пуассоновского потока

Поток строится последовательно: начиная с $t_0 = 0$, каждый следующий момент события вычисляется как:

$$t_{i+1} = t_i + \tau_i, \quad \tau_i \sim \text{Exp}(\lambda)$$

```python
def generate_poisson_stream(lam, T1):
    events = []
    t = 0.0
    while t < T1:
        # Генерируем интервал tau ~ Exp(lambda)
        # scale = 1/lambda -- математическое ожидание экспоненциального распределения
        tau = np.random.exponential(scale=1.0 / lam)
        t += tau
        if t < T1:
            events.append(t)
    return np.array(events)
```

### 3.3. Реализация Алгоритма 2

```python
def algorithm_2(lam, T, N):
    # T1 >> T: берём длину потока в 500 раз больше T
    T1 = max(500.0 * T, 5000.0 / lam)

    # Генерируем поток один раз
    stream = generate_poisson_stream(lam, T1)

    counts = np.empty(N, dtype=int)
    for k in range(N):
        # Случайное начало окна наблюдения
        a = np.random.uniform(0.0, T1 - T)

        # Подсчёт событий в [a, a+T) через бинарный поиск
        left  = np.searchsorted(stream, a,     side='left')
        right = np.searchsorted(stream, a + T, side='left')
        counts[k] = right - left

    return counts
```

Подсчёт событий в окне реализован через `numpy.searchsorted` - бинарный поиск по отсортированному массиву моментов. Это значительно быстрее, чем перебор всего потока в цикле.

## 4. Вычисляемые характеристики

### 4.1. Эмпирические характеристики

Вычисляются по выборке $X_1, X_2, \ldots, X_N$ - результатам $N$ экспериментов.

**Выборочное среднее** (оценка математического ожидания):

$$\hat{M} = \frac{1}{N} \sum_{j=1}^{N} X_j$$

**Выборочная дисперсия** (несмещённая оценка):

$$\hat{D} = \frac{1}{N-1} \sum_{j=1}^{N} (X_j - \hat{M})^2$$

Делитель $N-1$ (а не $N$) делает оценку **несмещённой**: в среднем по многим выборкам она точно попадает в истинное значение дисперсии. Деление на $N$ систематически занижало бы результат.

**Выборочное стандартное отклонение:**

$$\hat{\sigma} = \sqrt{\hat{D}}$$

Имеет те же единицы, что и сама величина, поэтому удобнее для содержательной интерпретации, чем дисперсия.

### 4.2. Теоретические характеристики

Из свойств распределения Пуассона:

$$M_{\text{теор}} = \lambda T, \qquad D_{\text{теор}} = \lambda T$$

### 4.3. Отклонения

**Абсолютное отклонение среднего:**

$$\Delta M = \hat{M} - \lambda T$$

**Относительная погрешность среднего:**

$$\delta_M = \frac{|\hat{M} - \lambda T|}{\lambda T} \cdot 100\%$$

**Абсолютное отклонение дисперсии:**

$$\Delta D = \hat{D} - \lambda T$$

**Относительная погрешность дисперсии:**

$$\delta_D = \frac{|\hat{D} - \lambda T|}{\lambda T} \cdot 100\%$$

### 5.3. Описание графика

На графике изображены два набора столбцов для каждого значения $k = 0, 1, 2, \ldots$:

- **Синие столбцы** - эмпирическое распределение $P^*(X = k)$: доля экспериментов, в которых наблюдалось ровно $k$ заявок за интервал $T$.
- **Оранжевые столбцы** - теоретическое распределение Пуассона $P(X = k) = \dfrac{(\lambda T)^k}{k!} e^{-\lambda T}$.

При достаточно большом $N$ синие столбцы вплотную приближаются к оранжевым, визуально подтверждая соответствие эмпирического распределения теоретическому закону Пуассона.

1. **Корректность алгоритма.** Генерация интервалов через экспоненциальное распределение с параметром $\lambda$ обеспечивает воспроизведение всех свойств пуассоновского потока: стационарности, ординарности и отсутствия последействия. 4. **Соответствие распределению Пуассона.** Построенное эмпирическое распределение числа заявок визуально и численно согласуется с теоретическим распределением Пуассона: столбцы гистограммы точно следуют форме теоретической кривой, а относительные погрешности по среднему и дисперсии не превышают заданного порога.

5. **Закон больших чисел.** При увеличении числа экспериментов $N$ статистические оценки устойчиво сходятся к теоретическим значениям, что соответствует закону больших чисел.

Таким образом, моделирование подтвердило теоретические характеристики пуассоновского потока: эмпирическое среднее и дисперсия совпадают с $\lambda T$, а эмпирическое распределение числа заявок соответствует закону Пуассона.
