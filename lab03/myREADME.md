# Лабораторная работа 3: Клеточные автоматы. Лесные пожары.

## 1. Цель работы

Реализовать моделирование возникновения и распространения лесных пожаров с использованием двумерного клеточного автомата. Требуется реализовать графический интерфейс пользователя для визуализации и управления симуляцией, а также внедрить не менее трёх дополнительных правил поведения системы (влияние температуры, влажности и водных преград).

---

## 2. Описание модели

### 2.1. Состояния клеток

Каждая клетка двумерной сетки размером **60 × 60** может находиться в одном из пяти состояний:

| Константа | Значение | Описание |
| :--- | :--- | :--- |
| `EMPTY` | 0 | Пустая земля |
| `TREE` | 1 | Дерево |
| `FIRE` | 2 | Горящее дерево |
| `ASH` | 3 | Пепел |
| `WATER` | 4 | Водная преграда |

### 2.2. Базовые правила перехода

Модель обновляется синхронно по тактам (используется двойная буферизация). Основные правила классического автомата:

1. **Горящая клетка** → на следующем шаге превращается в пепел.
2. **Пепел** → на следующем шаге развеивается и становится пустой клеткой.
3. **Пустая клетка** → с вероятностью $p$ (параметр «вероятность роста») на ней вырастает новое дерево.
4. **Дерево** → воспламеняется в двух случаях:
   * От удара молнии с вероятностью $f$ (параметр «вероятность молнии»), независимо от соседей.
   * От наличия хотя бы одного горящего соседа (в окрестности Мура) с вероятностью $P_{spread}$.

---

## 3. Дополнительные правила поведения системы

Для усложнения модели введены климатические и топографические факторы, влияющие на вероятность передачи огня от клетки к клетке ($P_{spread}$).

### 3.1. Температура и влажность

Погодные условия задаются двумя параметрами, настраиваемыми через пользовательский интерфейс:
* **Температура ($T$)**: варьируется от -50°C до +50°C. Повышенная температура увеличивает шанс возгорания, пониженная — уменьшает.
* **Влажность ($H$)**: варьируется от 0% до 100%. Высокая влажность выступает в роли естественного демпфера, замедляя или останавливая распространение огня.

Итоговая вероятность возгорания дерева от горящего соседа рассчитывается по формуле:

$$P_{spread} = \max\left(0.01, \min\left(1.0, 0.6 + \frac{T}{100} - \frac{H}{100}\right)\right)$$

Где $0.6$ — базовая вероятность передачи огня. Функция ограничивает итоговое значение в логичных математических рамках от 0.01 до 1.0.

### 3.2. Водная преграда (Топография)

Клетки с состоянием `WATER` выступают в качестве абсолютного изолятора:
* Они не могут загореться.
* На них не могут вырасти деревья (ни в процессе симуляции, ни при первичной генерации леса).
* Огонь не может распространяться сквозь водную преграду.

Пользователь имеет возможность вручную рисовать русла рек или озера любой формы с помощью инструмента «Водная преграда».

---

## 4. Генерация мира

При запуске симуляции или нажатии кнопки «Сгенерировать лес» происходит автоматическое заполнение сетки:
* Каждая пустая клетка (которая не является водой) становится деревом с вероятностью **40%**.
* Клетки с водой остаются неизменными, сохраняя заданную топографию.

---

## 5. Графический интерфейс

Приложение реализовано на встроенной библиотеке **tkinter**. Для оптимизации отрисовки используется точечное обновление пикселей холста (меняются только те ячейки, состояние которых изменилось на текущем такте).

### 5.1. Элементы управления

| Элемент | Назначение |
| :--- | :--- |
| **Панель статистики** | Отображение текущего тика, количества живых и горящих деревьев |
| **Ползунок «Скорость»** | Регулировка скорости симуляции (от 1 до 60 тиков/сек) |
| **Ползунок «Вероятность роста»** | Настройка $p$ (от 0.1% до 10.0%) |
| **Ползунок «Вероятность молнии»**| Настройка $f$ (от 0.01% до 1.0%) |
| **Ползунок «Влажность»** | Настройка $H$ (от 0% до 100%) |
| **Ползунок «Температура»** | Настройка $T$ (от -50°C до +50°C) |
| **Инструменты кисти** | Радиокнопки для рисования воды или удаления объектов (ластик) мышью на холсте |
| **Кнопки управления** | «Старт / Пауза», «Очистить поле», «Сгенерировать лес» |

### 5.2. Цветовая схема

Используется контрастная схема на фоне темного интерфейса (`#2b2b2b`):

* Пустота: `white` (белый)
* Дерево: `#00FF00` (ярко-зелёный)
* Огонь: `red` (красный)
* Пепел: `black` (чёрный)
* Вода: `blue` (синий)

---

## 6. Структура программы

Вся логика инкапсулирована в класс `ForestFireApp`.

* `__init__()` — инициализация состояния сетки и переменных симуляции.
* `_build_ui()` — сборка виджетов tkinter (холст, ползунки, кнопки).
* `_init_grid()` — первичная отрисовка графических примитивов (прямоугольников).
* `on_mouse_draw(event)` — обработчик событий мыши для рисования воды/ластиком.
* `generate_forest()` — алгоритм начального засева сетки.
* `tick()` — главный вычислительный метод. Рассчитывает новое поколение автомата с использованием окрестности Мура и планирует следующий вызов через `root.after()`.

## 7. Выводы

В ходе работы была успешно реализована математическая модель лесного пожара на базе двумерного клеточного автомата. Внедрение дополнительных физических параметров (температура, влажность, топография) позволило уйти от жестко детерминированной базовой модели и наблюдать сложные эмерджентные явления. 

Разработанный алгоритм перерасчета сетки с использованием двойного буфера и оптимизированной графической отрисовки показал высокую производительность, достаточную для плавной визуализации процесса в реальном времени. Интерактивный интерфейс дает возможность на лету менять параметры системы, выступая в роли полноценного инструмента для численных экспериментов.
