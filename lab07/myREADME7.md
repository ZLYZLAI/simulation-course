## Теоретические сведения

### Непрерывная цепь Маркова

**Непрерывная цепь Маркова (НВЦМ)** - случайный процесс $X(t)$, принимающий значения из конечного множества состояний $S = \{0, 1, \ldots, n-1\}$ в непрерывном времени $t \geq 0$, и обладающий **свойством Маркова**:

$$P\bigl(X(t+s) = j \mid X(t) = i,\; X(u),\; u < t\bigr) = P\bigl(X(t+s) = j \mid X(t) = i\bigr)$$

Будущее состояние зависит только от текущего и не зависит от предыстории. Время непрерывное: переходы происходят в произвольные моменты, а не строго раз в день. Погода может смениться несколько раз за день или оставаться неизменной несколько дней подряд.

### Матрица интенсивностей Q

Поведение НВЦМ полностью определяется **матрицей интенсивностей** (инфинитезимальным генератором) $Q = [q_{ij}]$:

- $q_{ij} \geq 0$ при $i \neq j$ - **интенсивность перехода** из состояния $i$ в $j$ ($\text{дн}^{-1}$), то есть скорость, с которой цепь уходит из $i$ в $j$
- $q_{ii} = -\sum_{j \neq i} q_{ij}$ - суммарная интенсивность **выхода** из состояния $i$, взятая с минусом

**Обязательное свойство:** каждая строка $Q$ суммируется в нуль:

$$\sum_{j=0}^{n-1} q_{ij} = 0, \quad \forall\, i$$

Это следует из определения: $q_{ii} = -\sum_{j \neq i} q_{ij}$.

### Время пребывания в состоянии

Время пребывания в состоянии $i$ до первого выхода из него распределено по **показательному (экспоненциальному) закону** с параметром $\lambda_i = |q_{ii}|$:

$$f(\tau) = \lambda_i\, e^{-\lambda_i \tau}, \quad \tau \geq 0$$

**Математическое ожидание** (среднее время пребывания в состоянии $i$):

$$M[T_i] = \frac{1}{\lambda_i} = \frac{1}{|q_{ii}|}$$

Экспоненциальное распределение обладает **свойством отсутствия последействия** (памяти):
$$P(T > s + t \mid T > s) = P(T > t)$$

Именно это свойство согласовано со свойством Маркова: «история» пребывания в состоянии не влияет на вероятность выхода.

### Вероятности переходов при выходе

При выходе из состояния $i$ вероятность попасть в следующее состояние $j$ определяется пропорционально интенсивностям:

$$p_{ij} = \frac{q_{ij}}{\lambda_i} = \frac{q_{ij}}{|q_{ii}|}, \quad j \neq i, \quad p_{ii} = 0$$

Эти вероятности образуют **вложенную (embedded) цепь Маркова**.

### Алгоритм Next-Event Simulation

Стандартный алгоритм точной симуляции НВЦМ:

1. Находясь в состоянии $i$, генерирую время пребывания:
$$T \sim \text{Exp}(\lambda_i), \quad T = -\frac{\ln U}{\lambda_i}, \quad U \sim \text{Uniform}(0,1)$$
2. Выбираю следующее состояние $j \neq i$ с вероятностью $p_{ij} = q_{ij}/\lambda_i$.
3. Сдвигаю модельные часы: $t \leftarrow t + T$.
4. Переходю в состояние $j$ и повторяю.

### Стационарное распределение

**Стационарное распределение** $\pi = (\pi_0, \pi_1, \ldots, \pi_{n-1})$ - вектор, не изменяющийся при эволюции процесса. Определяется из **уравнений глобального баланса**:

$$\pi \cdot Q = \mathbf{0}$$

$$\sum_{i=0}^{n-1} \pi_i = 1$$

**Физический смысл $\pi_i$** (эргодическая теорема для НВЦМ):

$$\lim_{T \to \infty} \frac{1}{T} \int_0^T \mathbf{1}\{X(t) = i\}\, dt = \pi_i \quad \text{(почти наверное)}$$

То есть $\pi_i$ - доля непрерывного времени, которую процесс в долгосрочной перспективе проводит в состоянии $i$, независимо от начального состояния $X(0)$.

### Связь с дискретной аппроксимацией

При дискретизации с шагом $\Delta t$ матрица переходных вероятностей:
$$P(\Delta t) = e^{Q \Delta t} \approx I + Q \cdot \Delta t \quad \text{(первое приближение)}$$

При $\Delta t = 1$ день: $P = I + Q$. Стационарное распределение не изменяется:
$$\pi P = \pi \;\Leftrightarrow\; \pi(I+Q) = \pi \;\Leftrightarrow\; \pi Q = \mathbf{0}$$

## Аналитическое вычисление стационарного распределения

Ищем $\pi = (\pi_0, \pi_1, \pi_2)$ из системы $\pi \cdot Q = \mathbf{0}$:

$$\begin{cases}
-0.4\,\pi_0 + 0.4\,\pi_1 + 0.1\,\pi_2 = 0 \quad (1) \\
\phantom{-}0.3\,\pi_0 - 0.8\,\pi_1 + 0.4\,\pi_2 = 0 \quad (2) \\
\phantom{-}0.1\,\pi_0 + 0.4\,\pi_1 - 0.5\,\pi_2 = 0 \quad (3) \\
\pi_0 + \pi_1 + \pi_2 = 1 \quad (4)
\end{cases}$$

Уравнения (1)–(3) линейно зависимы (сумма = 0), поэтому уравнение (3) заменяется на (4).

**Шаг 1.** Из уравнения (1) выражаю $\pi_1$:

$$0.4\,\pi_1 = 0.4\,\pi_0 - 0.1\,\pi_2 \implies \pi_1 = \pi_0 - \frac{1}{4}\,\pi_2 \quad (*)$$

**Шаг 2.** Подставляю $(*)$ в уравнение (2):

$$0.3\,\pi_0 - 0.8\!\left(\pi_0 - \frac{\pi_2}{4}\right) + 0.4\,\pi_2 = 0$$
$$-0.5\,\pi_0 + 0.2\,\pi_2 + 0.4\,\pi_2 = 0$$
$$0.6\,\pi_2 = 0.5\,\pi_0 \implies \pi_2 = \frac{5}{6}\,\pi_0 \quad (**)$$

**Шаг 3.** Из $(*)$ и $(**)$:

$$\pi_1 = \pi_0 - \frac{1}{4}\cdot\frac{5}{6}\,\pi_0 = \pi_0\!\left(1 - \frac{5}{24}\right) = \frac{19}{24}\,\pi_0 \quad (***)$$

**Шаг 4.** Условие нормировки:

$$\pi_0 + \frac{19}{24}\,\pi_0 + \frac{5}{6}\,\pi_0 = \pi_0\cdot\frac{24 + 19 + 20}{24} = \pi_0\cdot\frac{63}{24} = 1$$

$$\boxed{\pi_0 = \frac{24}{63} = \frac{8}{21} \approx 0.3810, \qquad \pi_1 = \frac{19}{63} \approx 0.3016, \qquad \pi_2 = \frac{20}{63} \approx 0.3175}$$

**Проверка $\pi \cdot Q = \mathbf{0}$** (нулевой компонент):

$$\frac{8}{21}\cdot(-0.4) + \frac{19}{63}\cdot(0.4) + \frac{20}{63}\cdot(0.1) = -\frac{3.2}{21} + \frac{7.6}{63} + \frac{2.0}{63} = -\frac{9.6}{63} + \frac{9.6}{63} = 0 \;\checkmark$$

**Интерпретация:** в долгосрочной перспективе 38.1% всего времени - ясно, 30.2% - облачно, 31.7% - пасмурно.

## Алгоритм моделирования

### Один переход (шаг симуляции)

```python
def step(self):
    i = self.current_state
    lambda_i = -self.Q[i, i]      # суммарная интенсивность выхода из i

    # Время пребывания: T ~ Exp(lambda_i)
    holding_time = np.random.exponential(scale=1.0 / lambda_i)

    # Вероятности переходов: p_ij = q_ij / lambda_i  (j != i)
    probs = np.array([
        self.Q[i, j] / lambda_i if j != i else 0.0
        for j in range(self.N)
    ])
    probs /= probs.sum()   # нормировка от численных ошибок

    # Случайный выбор следующего состояния
    next_state = int(np.random.choice(self.N, p=probs))

    # Обновляем статистику
    self.history.append((self.total_time, i, holding_time))
    self.total_time       += holding_time
    self.time_in_state[i] += holding_time
    self.n_transitions    += 1

    # Бегущие доли для графика сходимости
    for k in range(self.N):
        self.running_fractions[k].append(self.time_in_state[k] / self.total_time)

    self.current_state = next_state
```

### Вычисление стационарного распределения

Решается система $A \cdot \pi^{\top} = b$, где:

$$A = Q^{\top} \text{ (с заменой последней строки на } [1,1,1]\text{)}, \qquad b = [0,\,0,\,1]^{\top}$$

```python
def compute_stationary_distribution(self):
    A = self.Q.T.copy()
    b = np.zeros(self.N)
    A[-1, :] = 1.0    # условие нормировки
    b[-1]    = 1.0
    pi = np.linalg.solve(A, b)      # LU-разложение
    pi = np.maximum(pi, 0.0)        # устраняем численные ошибки
    return pi / pi.sum()
```

### Статистическая обработка

**Эмпирическая доля времени** в состоянии $i$:

$$\hat{\pi}_i = \frac{\text{time\_in\_state}[i]}{\text{total\_time}}$$

**Бегущая доля** (для графика сходимости) после $k$-го перехода:

$$\hat{\pi}_i^{(k)} = \frac{\text{time\_in\_state}[i]}{t_k}, \quad k = 1, 2, \ldots$$

**Абсолютное отклонение** от теоретического:

$$\Delta_i = \left|\hat{\pi}_i - \pi_i\right|$$

**Относительная погрешность, %:**

$$\delta_i = \frac{\left|\hat{\pi}_i - \pi_i\right|}{\pi_i} \cdot 100\%$$

## Визуализация результатов

### 1. Непрерывный поток состояний

**Что изображено:** ступенчатая функция $X(t)$ - состояние погоды в каждый момент непрерывного времени.

**Оси:** $X$ - суммарное модельное время (дни), $Y$ - состояние (0, 1, 2).

**Элементы:**
- **Цветные полосы фона** - жёлтая (Ясно), голубая (Облачно), серая (Пасмурно). Ширина полосы = время пребывания $T_i \sim \text{Exp}(\lambda_i)$ - **случайная**.
- **Горизонтальная чёрная линия** - уровень текущего состояния в течение интервала
- **Вертикальная черта** - момент случайного перехода между состояниями
- **Пунктир** - текущее незавершённое состояние
- Отображаются последние 50 завершённых интервалов

Ключевое отличие от дискретной цепи: полосы имеют **разную ширину** (случайную), так как время непрерывное. Видно, что ясная погода держится дольше (шире полосы), а облачная - короче.

### 2. Распределение времени в состояниях

**Что изображено:** столбчатая диаграмма сравнения двух распределений:

- **Синие столбцы** - эмпирика: $\hat{\pi}_i = \text{time\_in\_state}[i] / \text{total\_time}$
- **Розовые столбцы** - теория: $\pi_i$ из решения $\pi Q = \mathbf{0}$

Чем больше переходов - тем ближе синие столбцы к розовым.

### 3. Сходимость к Q-стационарному

**Что изображено:** кривые бегущих долей $\hat{\pi}_i^{(k)}$ против числа переходов $k$ для каждого состояния. Горизонтальные пунктиры - теоретические $\pi_i$.

**Как читать:** вначале кривые хаотично осциллируют, затем постепенно «успокаиваются» и прижимаются к пунктирным линиям - это **эргодическая теорема в действии**.

## Вывод

В ходе лабораторной работы была реализована имитационная модель смены погоды на основе непрерывной цепи Маркова с матрицей интенсивностей $Q$ из лекционных слайдов.

1. **Корректность алгоритма.** Метод Next-Event Simulation точно воспроизводит свойства НВЦМ: экспоненциальное распределение времён пребывания и вероятностный выбор следующего состояния. Время непрерывное - переходы происходят в произвольные моменты.

2. **Среднее время пребывания.** Теоретически $M[T_0] = 2.5$, $M[T_1] = 1.25$, $M[T_2] = 2.0$ дней. Облачная погода наименее устойчива, ясная - наиболее. Это визуально подтверждается шириной полос на первом графике.

3. **Стационарное распределение.** Аналитическое решение $\pi Q = \mathbf{0}$ даёт $\pi_0 = 8/21 \approx 38.1\%$, $\pi_1 = 19/63 \approx 30.2\%$, $\pi_2 = 20/63 \approx 31.7\%$. При $N = 1000$ переходов относительные отклонения не превышают 2–3%, при $N = 5000$ - менее 1%.

4. **Сходимость и эргодическая теорема.** График сходимости наглядно демонстрирует: эмпирические доли времени монотонно стремятся к теоретическим $\pi_i$. Скорость убывания погрешности $O(1/\sqrt{N})$ - характерная для закона больших чисел.

5. **Неизменность стационарного распределения.** Поскольку $P = I + Q$ и $\pi P = \pi \Leftrightarrow \pi Q = \mathbf{0}$, стационарное распределение одинаково для непрерывной и её дискретной аппроксимации. Численные значения $\pi_i$ не зависят от способа моделирования.

6. **Практическое применение.** Разработанный программный комплекс позволяет задавать произвольную матрицу $Q$, наблюдать непрерывный процесс в реальном времени и сохранять полную статистику в CSV-файлы. НВЦМ применяется в задачах прогнозирования погоды, моделировании систем массового обслуживания, анализе надёжности оборудования и других областях, где смена состояний происходит в непрерывном времени.
