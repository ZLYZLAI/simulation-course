# Отчёт по лабораторной работе: Моделирование случайных событий

## 1. Задача

Реализовать программную имитацию случайных событий на основе базового датчика случайных чисел:
1. Моделирование наступления одного случайного события (вероятность "Да/Нет").
2. Генерация события из полной группы попарно несовместных событий ("Магический шар").

## 2. Описание математической модели

### 2.1. Базовый датчик (БД)
Основой стохастического моделирования в данной работе является базовый датчик, генерирующий псевдослучайное число $\alpha$, равномерно распределенное в полуинтервале $[0, 1)$. Геометрический смысл вероятности в данном случае заключается в том, что вероятность попадания значения $\alpha$ в любой подотрезок внутри $[0, 1)$ численно равна длине этого подотрезка.

### 2.2. Моделирование одного случайного события (Лабораторная 5.1)
Для моделирования события $A$ с заданной вероятностью наступления $p = P\{A\}$ применяется следующий алгоритм:
1. Генерируется число $\alpha$ от базового датчика.
2. Проверяется условие:
   * Если $\alpha < p$, то считается, что событие $A$ наступило.
   * Если $\alpha \ge p$, то наступило противоположное событие $\bar{A}$.

В рамках задачи (приложение «Да/Нет») исходы равновероятны, поэтому $p = 0.5$.

### 2.3. Генерация события из группы несовместных событий (Лабораторная 5.2)
Имеется полная группа из $m$ попарно несовместных событий $A_1, A_2, \dots, A_m$ с соответствующими вероятностями $p_1, p_2, \dots, p_m$. Так как группа полная, выполняется условие нормировки:
$$\sum_{i=1}^{m} p_i = 1$$

Для генерации конкретного исхода применяется метод последовательного суммирования вероятностей (нахождение интервала):
1. Отрезок $[0, 1]$ разбивается на $m$ интервалов, длина каждого $i$-го интервала равна $p_i$.
2. Генерируется псевдослучайное число $\alpha$.
3. Накапливается кумулятивная вероятность $P_{cum} = \sum_{j=1}^{k} p_j$.
4. Фиксируется наступление события $A_k$, для которого впервые выполняется неравенство $\alpha < P_{cum}$.

В приложении «Магический шар» представлено $m = 8$ вариантов ответа. При условии их равновероятности, вероятность каждого исхода составляет:
$$p_k = \frac{1}{m} = 0.125$$

## 3. Программная реализация математических моделей

Вычислительная часть изолирована от графического интерфейса. В качестве базового датчика используется стандартная функция `random.random()` языка Python.

### 3.1. Математика случайного события (Да/Нет)

```python
import random

def roll_yes_no():
    # 1. Получаем значение от базового датчика (alpha in [0.0, 1.0))
    alpha = random.random()
    
    # 2. Задаем вероятность наступления события
    p = 0.5
    
    # 3. Проверяем геометрическое условие
    if alpha < p:
        return "Ага"
    else:
        return "Не ага"  
```

### 3.2. Математика полной группы событий (Магический шар)

```python
import random

def get_magic_ball_prediction():
    # 1. Обращение к базовому датчику
    alpha = random.random()
    
    answers = [
        "Да", "Нет", "Скорее всего", "Сомнительно", 
        "Без сомнений", "Спроси позже", "Определенно да", "Маловероятно"
    ]
    
    # 2. Вычисление вероятностей p_k для равновероятных событий
    m = len(answers)
    p_k = 1.0 / m  # 0.125
    
    # 3. Алгоритм поиска интервала
    cumulative_probability = 0.0 
    
    for i in range(m):
        # Накопление суммы вероятностей
        cumulative_probability += p_k
        
        # Проверка попадания alpha в текущий интервал
        if alpha < cumulative_probability:
            return answers[i]
```
